# Lessons (append-only, dated; ACE-style deltas, never rewrite history)

- [2026-10-24] Do not rebuild the agent harness: Claude Code / OpenCode / Cline already ship loops, tools, subagents, hooks, MCP, AGENTS.md.
- [2026-10-24] A hand-rolled OpenAI-compatible proxy breaks tool-using clients; use LiteLLM (`ollama_chat/` for tools, `/v1/messages` for Claude Code).
- [2026-10-24] Run Ollama natively on Windows, not in Docker. One large local model resident at a time on 12 GB.
- [2026-10-24] Haiku 5.5 at $0.10/$0.50 per MTok changes the local-vs-cloud break-even; local pays off for privacy, autocomplete and the MoE tier.
- [2026-10-24] Since 2026-10-21 `temperature`/`top_p`/`top_k` return HTTP 400 on every Claude model; `output_config.effort` is the cost lever. Set temperature only on local deployments.
- [2026-10-24] Keep one source of truth for department prompts (`agents/*.yaml`) and generate per-tool files; duplicated prompts drifted within one session.
- [2026-10-24] Self-development is a human-gated nightly PR loop with an eval gate, never auto-merge.
- [2026-10-24] Ollama >= 0.30 runs GGUF through upstream llama-server with `LLAMA_ARG_FIT=on`, which is MoE-aware (experts to CPU, attention on GPU). A separate llama-server install is unnecessary; `LLAMA_ARG_N_CPU_MOE=N` passes through as a manual override.
- [2026-10-24] The handoff assumed Ollama, Docker and Open WebUI were installed; none were. Always run `stack.py doctor` before trusting a handoff's environment claims.
- [2026-10-24] Claude Code reads AGENTS.md natively only when no CLAUDE.md exists; a CLAUDE.md that `@AGENTS.md`-imports it keeps both tools and the memory files in context.
- [2026-10-24] In `.mcp.json`, env var names that look like credentials (`*_API_KEY`, `*_TOKEN`) read as empty; name the orchestrator bearer `ORCHESTRATOR_BEARER`.
- [2026-10-25] Ollama 0.40 disables mmap by default on Windows+CUDA ("windows_cuda" in server/sched.go), copying CPU-side MoE experts into anonymous RAM. With desktop apps holding ~20 GB, the 35B load paged and hit the 5-minute `OLLAMA_LOAD_TIMEOUT` (HTTP 500). Send `use_mmap: true` per request (LiteLLM forwards it into Ollama `options`) and raise the timeout.
- [2026-10-25] On this box the MoE primary decodes at ~25 tok/s versus ~52 for the dense 9B, and leaves ~1 GB of RAM available instead of ~18 GB. Benchmark both before choosing; RAM pressure, not VRAM, is the binding constraint.
- [2026-10-25] Processes started from an agent's tool shell die when that session ends (job object). Launch services with CREATE_BREAKAWAY_FROM_JOB and the Ollama tray app through explorer.exe.
- [2026-10-25] Windows reuses pids: never kill or trust a pid file without checking the process image name.
- [2026-10-25] Correction to the CREATE_BREAKAWAY_FROM_JOB bullet above: services started that way from a Claude Code tool shell still stopped when the session restarted. Persistent services need a launcher outside the session (Task Scheduler, a logon item, or the owner's own terminal).
- [2026-10-25] Smart App Control can block unsigned uv tool launchers (`~/.local/bin/*.exe`) file by file: phoenix.exe was blocked (WinError 4551) while litellm.exe still ran. Service start must warn and continue, never abort the batch.
- [2026-10-25] When two gateway tiers share one Ollama model, give them the same num_ctx and load options; any difference makes Ollama reload the runner on every switch between tiers.
- [2026-10-25] Start uv tools through their environment's python.exe (`python -P -c` calling the console-script entry point from entry_points.txt), not the `~/.local/bin` launchers. Smart App Control blocked the per-script launcher (each one is a unique unsigned file) but allows the environment's standard python.exe.
- [2026-10-25] Identify a running service by pid plus process start time (Windows GetProcessTimes, Linux /proc/<pid>/stat field 22), not by executable path: every `uv run` is the same uv.exe, and on Linux a venv's python resolves to the shared base interpreter.
- [2026-10-25] Correction to the persistence bullets above: services started with CREATE_BREAKAWAY_FROM_JOB stopped with one Claude Code session and survived the next restart. Persistence across sessions is unreliable, not impossible.
- [2026-10-25] A tray app launched through Explorer (pythonw + a .lnk) is the reliable way to keep the services outside any terminal or agent session. In pystray on Windows, serialise icon updates: two threads swapping the icon image at once fail with WinError 1402.
- [2026-10-25] Start Windows services with CREATE_NO_WINDOW, not DETACHED_PROCESS. A venv Scripts\python.exe and uv.exe are launchers that start the real interpreter as a console child; under a DETACHED_PROCESS parent that child gets its own visible console window, and closing it kills the service. CREATE_NO_WINDOW gives the whole tree one hidden console. Stop by process tree and by the port's listener, and read status from the health check, never from a Popen handle.
- [2026-10-26] Privacy add-ons (skills, hooks, MCP checks) for clients that talk to their own cloud can only advise, yet suggest enforcement. Count a client as protected only when its sole model endpoint is the gated gateway.
- [2026-10-26] LiteLLM's `user_header_name` end-user mapping fails open without Postgres: the end-user lookup raises "No db connected", is logged at debug level, and the request passes unrestricted. Enforce per-user model access with `custom_auth` plus `enable_post_custom_auth_checks: true`; without that flag only `/v1/models` is filtered.
- [2026-10-26] A LiteLLM pre-call hook that raises a plain exception yields HTTP 500, which the router retries (three attempts) and may answer from a fallback. Gate refusals must raise a non-retryable 4xx.
- [2026-10-26] Check model licences before naming a tool in a plan: NudeNet looked like the obvious nudity detector but is AGPL-3.0, weights included.
- [2026-10-26] Long scratch or install paths on Windows break spaCy DLL loads and the Hugging Face cache past 260 characters; keep Python environments for ML models on short paths.
- [2026-10-26] Task Scheduler's "restart on failure" does not restart a task whose process exits non-zero or is killed. Add a repeating time trigger with MultipleInstancesPolicy IgnoreNew as a watchdog, and disable the task on a deliberate stop so the watchdog does not revive it.
- [2026-10-26] A supervisor that puts itself in a kill-on-close job object before spawning takes the whole service tree down when it dies; children inherit the job, so there is no spawn-to-assign race.
- [2026-10-26] Smart App Control judges compiled Python extensions (.pyd) one by one, not only executables: it blocked pyarrow, sqlalchemy and pandas modules inside the Phoenix tool env after they had run the day before.
- [2026-10-26] Keycloak's `kc.bat` caps the heap at 512 MB by default; a small realm stays near 0.5 GB working set, well under the 1.25 GB sizing-guide baseline written for production load.
- [2026-11-01] Ten parallel research subagents share one WebSearch budget, which ran out mid-task, and the fan-out (about 400k tokens per agent) hit the plan's session limit. Use fewer agents or stagger them, and tell agents to fetch primary pages directly once search runs out.
- [2026-11-01] The desktop app's built-in browser reports a 0x0 viewport and records no LCP while its pane is hidden. Set a viewport size (resize_window) before measuring a page, and treat zero-size results as invalid.
- [2026-11-01] On Windows a TCP connect to a closed localhost port takes about 2 s before it is refused, so health checks of several stopped services must run in parallel (tray status 8.1 s to 2.1 s). Never run that kind of I/O, or a PowerShell call, between a click and its visible feedback.
- [2026-11-01] ttk's clam theme draws a widget border only for relief solid or raised, and a custom layout without the `X.focus` element hides keyboard focus. Map `relief=solid` plus `bordercolor` on "focus" for a 2 px ring, and bind `TCombobox` `<MouseWheel>` to scroll the parent and return "break", or the wheel changes a read-only box.
- [2026-11-01] Parallel agents given `isolation: worktree` started at the repository's default branch, not the session's HEAD. Name the base commit in each brief and have the agent reset to it; give each agent separate regions of a shared file, then cherry-pick and fix the seams (one agent's import cleanup removed a name another commit used).
- [2026-11-01] `stack.py setup` ran `ollama pull` with check=False and printed "setup complete" after four pulls failed (models folder on an unplugged USB drive, HTTP 400 mkdir). Pull through `/api/pull` with streaming and raise on its `error` field, and check that a folder's drive exists before writing it anywhere.
- [2026-11-01] Smart App Control refused `.venv\Scripts\pythonw.exe` of a venv built from uv's own (unsigned) Python while the same venv's python.exe still ran. A venv built from a python.org Python gets PSF-signed launchers that run; `python-preference = "system"` in pyproject makes uv pick it, and `.python-version` must not pin a version only uv-managed Python provides.
- [2026-11-01] `winsat disk` without administrator rights prints nothing and exits 0. Check elevation first; otherwise time a test file written with fsync and read back with FILE_FLAG_NO_BUFFERING (a normal read comes from the file cache).
- [2026-11-01] A USB SSD reading ~40 MB/s for sequential, random and write alike is on a USB 2.0 link. Turning the USB-C plug over took the Crucial X8 from 41 to 376 MB/s: one orientation's SuperSpeed contacts were bad. Measure the models drive before blaming Ollama for slow cold loads.
- [2026-11-04] Ollama keeps the keep_alive of the most recent request for a runner, so gateway aliases that share one model must not send different values (local-small's 30m silently ended local-primary's -1). Leave keep_alive to OLLAMA_KEEP_ALIVE and warm the model at start-up with the same num_ctx and options as the gateway; a cold 9B load from the USB SSD at 376 MB/s took 23 s.
- [2026-11-03] OpenClaw (2026.10.9) can be set up without questions: `openclaw onboard --non-interactive --accept-risk --auth-choice custom-api-key --custom-provider-id <id> --custom-base-url .../v1 --custom-model-id <alias> --secret-input-mode ref` plus the `--skip-*` flags. Later changes go through `openclaw config patch --stdin`, because its config schema is strict and a hand-written key stops its gateway. On Windows, call `node <npm prefix>\node_modules\openclaw\openclaw.mjs`, not the npm `.cmd` shim, which runs through cmd.exe and can mangle JSON arguments. Test it with USERPROFILE pointed at a scratch folder, so the owner's ~/.openclaw is untouched.
- [2026-11-03] A test helper that returned a closure from inside its `with mock.patch(...)` block ran the step after the mocks had closed, and onboarded the owner's real ~/.openclaw. Call the code under test inside the `with`, and in a test module for code with side effects outside the repo, block the real entry points module-wide (setUpModule) so a leak fails instead of acting.
- [2026-11-04] Smart App Control judged PyAV wheels version by version inside ComfyUI's venv: 19.0.2 and 16.0.1 were refused (cp314 and cp312), 17.0.0 ran. Test candidate versions in throwaway venvs, pin the one that loads, and import every compiled dependency right after install so a refusal fails setup, not the first start.
- [2026-11-04] Open WebUI 0.12 seeds its config table from environment variables only for keys it does not have yet, then reads the table on every request. Setting env vars does nothing on an existing install; write the rows (after a backup) and reload the page, no restart needed. SQLite stores numeric JSON values as integers there, so read them back with that in mind.
- [2026-11-04] Python's `-P` drops the script's own folder from sys.path, not only the working directory. Use it for console-script entry points, never for an app started as `python main.py` that imports its own packages (ComfyUI).
- [2026-11-05] faster-whisper on Windows: ctranslate2 4.8 finds CUDA devices but fails at the first encode with "cublas64_12.dll is not found". Install nvidia-cublas-cu12 and nvidia-cudnn-cu12 (9.x) into the venv and put their `site-packages/nvidia/*/bin` folders on PATH before importing it; os.add_dll_directory is not enough for its LoadLibrary calls. large-v3-turbo int8_float16 then needs ~1.1 GB of VRAM.
- [2026-11-05] `Path("name.<key>").with_suffix(".md")` replaces the key, not appends to it: cache files named stem.key.ext collided until built with `with_name(base.name + ext)`.
- [2026-11-07] qwen3.5:9b through LiteLLM thinks by default: a 400-token cleanup request came back with empty content after 49 s. Send `"think": false` in the request body (LiteLLM forwards it to Ollama) for short utility calls; the same request then took 0.8 s.
- [2026-11-07] CTranslate2's Windows wheel bundles cuDNN but not cuBLAS. Ollama ships NVIDIA-signed `cublas64_12.dll` in `lib\ollama\cuda_v12`; adding that folder with os.add_dll_directory and PATH runs faster-whisper on the GPU without the 0.5 GB nvidia-cublas-cu12 wheel.
- [2026-11-07] Tk 9.0's `clipboard_clear` crashes Python 3.14.7 on Windows with an access violation. Use the Win32 clipboard through ctypes, opened with an owner window created on the same thread.
- [2026-11-07] Python's http.server sets SO_REUSEADDR, which on Windows lets a second process bind a port already in use. Set `allow_reuse_address = False` when a bind is meant to fail for a second instance.
- [2026-11-07] faster-whisper asks huggingface.co for the newest revision on every model load, even with the model cached. Load with `local_files_only=True` first and download only when that raises LocalEntryNotFoundError.
- [2026-11-07] The Claude desktop app registers Ctrl+Alt+Space globally (quick entry); RegisterHotKey fails with error 1409. Probe candidate hotkeys with RegisterHotKey on the machine before choosing a default.
- [2026-11-07] An auto-mode session may not capture the screen. Check a window by its Win32 state instead (GetWindowRect, extended styles) and leave its look to the owner.
- [2026-11-07] Never inject Ctrl+V or typed text while the user may still hold modifiers (hold-to-talk on Ctrl+Alt+<key>): Windows combines them into Ctrl+Alt+V or Alt+letter. Wait for Ctrl, Alt, Shift and Win to be up, and hold live text until the hotkey is released.
- [2026-11-07] Do not leave a window of yours as the clipboard owner on a thread without a message loop: another program's EmptyClipboard sends it WM_DESTROYCLIPBOARD synchronously and may wait on it. Create the owner window per clipboard operation and destroy it after CloseClipboard (pyperclip's pattern); the data stays. Found in review, not observed as a hang.
- [2026-11-07] A reinstall from a main checkout 10 commits behind origin/main installed an old stack: no voice typing step, no Start menu entry, and no message saying why. The installer now fetches and warns when the checkout is behind origin's default branch; pull before reinstalling.
- [2026-11-07] Smart App Control blocked the pytest.exe launcher that `uv run --with pytest pytest` put in a fresh ephemeral environment (os error 4551), minutes after the same command had worked. `uv run --with pytest python -m pytest` goes through the signed python.exe and runs.
- [2026-11-07] Claude Code settings that are easy to get wrong (docs for 2.1.319): CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC set to 0 or false still disables the traffic (unset it); Grep, Glob and Write deny rules with a path never match (use Read or Edit rules); without desktopSessionCleanupPeriodDays, transcripts of Desktop and Cowork sessions are kept at any age; Read deny rules don't stop a script that opens the file itself, and native Windows has no sandbox.
- [2026-11-07] Since Claude Code 2.1.319, telemetry or feature flags off means auto mode loses its server-side review and asks or denies instead; CLAUDE_CODE_AUTO_MODE_SERVER=0 brings back the built-in classifier. Privacy switches can cost features: read the changelog before recommending one.
- [2026-11-07] The Windows user name appears in more forms than C:\Users\<name>: //c/Users/<name> in permission rules, /c/Users/<name> in Git Bash, C:\\Users\\<name> in JSON, C--Users-<name>- in Claude's project folders, and bare in prose such as ACL lists. Redact every form, and check outputs by counting the real values in memory, never by printing them.
- [2026-11-07] Test a new skill with a fresh agent that has only its SKILL.md and the user's request. It found what the author's own runs missed: `scrub` changed only the current folder while `collect` reported other checkouts, claude.ai account UUIDs joined by `_` slipped past a `\b` pattern, a `*_MASTER_KEY` secret and `python -c ' *` allow rules went undetected, and real changelog security fixes went unmarked.
- [2026-11-07] LiteLLM's trace provider names the API adapter, not where the model ran: an Ollama model reached through /v1/messages was logged with provider "anthropic". Decide local versus outside API from the deployment's model_info (data_class, location) or the served model's `ollama/` prefix.
- [2026-11-07] "Every model call goes through the gateway" was not true: Open WebUI sent document embeddings straight to Ollama (RAG_EMBEDDING_ENGINE=ollama), Open WebUI calls ComfyUI directly, and Whisper runs in its own processes. Inventory each path (HTTP calls, model libraries, services calling each other) before trusting a usage count, and keep a tripwire test over the source (tests/test_tray_coverage.py) so new paths cannot slip past.
- [2026-11-07] ComfyUI keeps finished jobs in memory with millisecond timestamps (GET /history: status.messages execution_start and execution_success, extra_data.create_time, client_id, comfy_usage_source "comfyui-frontend" for its own page). Read usage from there instead of patching ComfyUI, and ask for a few with max_items: each job carries its whole workflow.
- [2026-11-07] Code that records usage must keep only finite numbers and swallow write errors: a test double's MagicMock reached json.dumps and raised TypeError. Tests must turn recording off (tests/conftest.py) or they append records to the checkout's real traces.
- [2026-11-07] Python's Path.write_text on Windows writes CRLF, while this repository keeps LF (.gitattributes eol=lf). Git normalises on commit, but the working copy then differs from a fresh checkout. Patch files with write_text(..., newline="\n") or as bytes.
- [2026-11-07] Open WebUI 0.12's speech-to-text engine "openai" posts the file from an async generator through aiohttp, so the request has Transfer-Encoding: chunked and no Content-Length; a stdlib http.server endpoint must decode chunked bodies itself (Python 3.13+ has no cgi module for the multipart part either). The seeded `audio.stt.openai.api_base_url` on this install was https://api.openai.com/v1, so the engine, URL and key rows must change together or recordings leave the machine. Without ffmpeg on PATH Open WebUI forwards the browser's webm/opus unchanged, and PyAV decodes it.
- [2026-11-07] Answer a refused upload only after reading its body to the end. Closing a socket with unread data sends a reset: on Windows, with a 3 MB POST to http.server answered 401 unread, the client got ConnectionAbortedError in 2 of 5 tries instead of the 401; reading the body first gave the 401 every time.
- [2026-11-07] Cap decoded audio, not only the upload: a 494 KB FLAC of digital silence declared 45 minutes, and 25 MB of it would decode to about 9 GB of float32 samples. Check the container's duration first (FLAC and Ogg carry it), then count samples while decoding, because a browser's MediaRecorder webm has no duration in its header.
- [2026-11-07] Ctrl+C is the one way that reads another app's selection everywhere on Windows. Save the clipboard before it and put it back after, and press Ctrl+C again right before Ctrl+V to confirm the same text is still selected in the same window. Never press Ctrl+C where nothing should be selected: in a terminal, VS Code's included, it stops the running program.
- [2026-11-07] A check that a rewrite is not an answer must not reject replies that start with "Here's": qwen3.5:9b rewrote "This are the first paragraph" as "Here's the first paragraph." Look for "Sure!"/"Certainly,", a refusal, or a preamble that ends in a colon.
- [2026-11-07] For end-to-end tests of text insertion, use a plain Win32 EDIT control (ctypes) or an Edge `--app` window with its own `--user-data-dir` as the target, not a Tk Text widget (its Ctrl+C goes through Tk's clipboard code, which crashes Python 3.14.7). Drive Word over COM with a new document closed without saving; PowerShell's `$word.Quit(0)` fails on the ByRef argument, so call `Quit()` once no document is open.
- [2026-11-07] A Tk menu that calls the app by method name fails only when clicked: a renamed method and a class inserted in the middle of another (which took three of its methods along) passed every unit test and three live runs that never opened a menu. A test that reads overlay.py with `ast` and checks each `app.<name>` against the App class catches both; open every menu once in a live check.
- [2026-11-07] Do not unregister a hotkey from inside its own WM_HOTKEY handler when unregistering waits for the hotkey thread's answer: the thread waits on itself and every hotkey freezes for the 3 s timeout. Hand the work to another thread, as voice typing's own Esc cancel does through its command queue.
- [2026-11-07] This repository is public, and it published the computer's name (a machine profile named after it, then copied into 40 docs), the Windows account's home path, and a stray Open WebUI database holding the live gateway key. Keep per-machine files untracked and written by the installer, write "the owner" and placeholders in docs, ignore `*.db`, and let a test scan files git would publish for the machine's own names, read at test time so the test stores none.
- [2026-11-07] Untracking a file that a checkout has edited locally: a plain `git pull` refuses ("local changes would be overwritten"), and `git rm --cached` first makes it refuse again ("untracked working tree files would be removed by merge"); once the path is gitignored, git treats the file as expendable. Copy the file out of the repository, `git checkout -- <file>`, pull, copy it back.

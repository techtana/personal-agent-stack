# Tray app that owns the services

**Status:** done 2026-10-26 in [PR #3](https://github.com/techtana/personal-agent-stack/pull/3). One check left:
confirm the tray and its services come up on their own after a sign-in.

## Goal

Keep Phoenix, LiteLLM, the orchestrator and Open WebUI running independently of any terminal or Claude Code
session. Services started from an agent's tool shell died with the session, and `CREATE_BREAKAWAY_FROM_JOB` did not
fix it reliably (`memory/lessons.md`, 2026-10-25).

## Approach

- A windowless tray process (`.venv\Scripts\pythonw.exe scripts\tray.py`) launched through Explorer, so it belongs to
  no terminal job. `stack.py tray` starts it; `scripts/stacklib/startup.py` handles single instance and start at login.
- The icon is green, amber or red by service health; a status window offers Open, Start/Stop, logs and a
  **Start at login** checkbox (a Startup-folder shortcut, `Agent Stack.lnk`).
- "Quit (keep services running)" and "Stop services and quit" are separate menu items.
- New dependencies: `pystray`, `pillow`.

## Outcome (2026-10-27)

Start at login is on for SEKAIHOME. The window was redesigned in
[2026-10-26-tray-status-window.md](2026-10-26-tray-status-window.md). For edge mode (services before sign-in),
Task Scheduler supervision (PR #7) takes over and the tray only shows status for task-run services.
